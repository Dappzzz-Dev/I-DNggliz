# Personal portfolio template

This is a small, static portfolio made with HTML, CSS, and vanilla JavaScript. It has no build step or package dependencies. Open `index.html` in a browser to preview it.

## What to edit

- **Text, projects, and links:** edit the matching sections in `index.html`.
- **Your photos:** optimized images are in `assets/photos/`. The first eight Photo Journal entries are in `index.html`; the rest are listed in `photoJournalEntries` in `script.js`. Replace a file while keeping its name, or update the matching entry and image path.
- **Photo sizing:** Photo Journal and My Pictures keep each image's original proportions. The journal archive is stored in `assets/photos/journal/` and loads lazily as you scroll.
- **Project screenshots:** optimized local previews are in `assets/projects/`.
- **Social profiles and music:** update the links and Spotify player URL in the Contact section.
- **Colors, layout, and typography:** adjust the variables at the top of `styles.css`.
- **Interactions:** `script.js` handles the mobile menu, floating Spotify player, desktop animations, image fallbacks, the Snake game, and current year. Start the game, then use the arrow keys, WASD, or the on-screen direction buttons.

Project details are based on the public portfolio at [pamer-co.vercel.app](https://pamer-co.vercel.app/). The blog references the supplied English assignment and class text for William Shakespeare’s *A Midsummer Night’s Dream*. Replace any details that change.
